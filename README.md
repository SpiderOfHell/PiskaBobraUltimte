# Викторина с таймером — вариант № 42

Практическая работа № 3 по дисциплине «Подходы для разработки программного обеспечения».

## Возможности

- запуск викторины и последовательный показ вопросов;
- отдельный реальный таймер на каждый вопрос (`time.monotonic` + `threading.Timer`);
- автоматическое закрытие вопроса по истечении лимита;
- блокировка позднего ответа и запрет начисления баллов за него;
- подсчёт баллов за правильные ответы;
- консольный интерфейс.

## Требования

Python 3.10 или новее.

## Установка

```bash
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows PowerShell:
.venv\Scripts\Activate.ps1

python -m pip install -e ".[test]"
```

## Запуск приложения

```bash
python -m quiz_app
# или после установки:
timed-quiz
```

На каждый вопрос в демонстрационной викторине даётся 15 секунд. Таймер работает независимо от ввода пользователя.

## Запуск тестов

```bash
python -m pytest -v
python -m behave
```

Тесты TDD и SDD используют внедряемые часы и тестовый таймер, поэтому не зависят от случайных задержек ОС. ATDD дополнительно проверяет работу настоящего таймера. BDD-сценарии выполняются через Behave.

## Подходы разработки

- **TDD:** модульные тесты для начисления баллов, отказа позднему ответу, таймера и граничного момента времени.
- **ATDD:** проверки законченных пользовательских сценариев: пройти вопросы, получить балл и не получить балл после тайм-аута.
- **BDD:** сценарии на русском Gherkin в `features/quiz.feature`, автоматизированные шаги — в `features/steps/quiz_steps.py`.
- **SDD:** табличные примеры входных данных, времени, результата и счёта реализованы параметризованным тестом.
